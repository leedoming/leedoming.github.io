PRODUCT FLOW

대화와 분석이 동시에 보이도록 연결했습니다.

Nova Sonic의 실시간 음성과 텍스트를 DB에 로깅하고, 축적되는 대화 내용을 Bedrock Agent에 전달했습니다. Agent의 분석 결과는 문법 교정, 추가 질문, 추천 표현으로 나눠 UI에 실시간 표시했습니다.

ARCHITECTURE DECISION

대화 세션과 피드백 처리를 분리했습니다.

처음에는 Nova Sonic의 tool calling으로 Agent를 직접 호출하려 했습니다. 하지만 도구 응답을 기다리는 동안 음성 대화도 중단되는 제약을 확인해, 대화는 계속 유지하고 분석·피드백은 별도 Agent 흐름에서 처리하도록 설계했습니다.
